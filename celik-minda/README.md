# Celik Minda 6 Tahun

Modul statik untuk Jom Main & Belajar, boleh dicapai melalui `./celik-minda/`.

Pengguna memilih Set 5, 6 atau 7 dan menjawab satu kertas lengkap. Setiap set mempunyai 10 helaian, mengikut susunan rujukan PDF: Bahasa Melayu (4), Bahasa Arab (1), Bahasa Inggeris (1), Jawi (2), Matematik (1), Sains & Teknologi (1). Tiada mod memilih subjek secara berasingan. Navigation antara helaian digunakan untuk menyemak jawapan dalam set yang sama.

Jumlah setiap set: 100 markah, dengan pecahan 40/10/10/20/10/10. Markah dan skema hanya ditunjukkan selepas pengguna menghantar set. Jawapan kosong mendapat 0. Soalan pilihan berbilang mendapat markah penuh hanya apabila semua pilihan tepat; arahan ini dipaparkan pada soalan berkenaan. Jawapan susunan nombor menerima pemisah koma atau ruang. Huruf besar dan kecil diperiksa secara tepat dalam aktiviti menyalin dan padanan huruf.

Soalan ialah latihan baharu berdasarkan kemahiran dan bentuk soalan rujukan, bukan kertas rasmi PASTI. Padanan gambar ditukar kepada pilihan gambar; jawapan bertulis ditaip. Menulis tangan masih memerlukan latihan kertas. Ilustrasi SVG asal disertakan tanpa permintaan rangkaian. Nama pilihan dan jawapan hanya berada dalam localStorage pelayar; tiada login, database, analitik atau penghantaran data. Jika localStorage tidak tersedia, pengguna masih boleh menjawab sepanjang halaman terbuka.

Fail: `questions.js` (data set dan markah), `illustrations.js` (SVG), `app.js` (helaian, jawapan, simpan, semakan), `style.css` (paparan responsif dan cetakan). Tambahan dalam `../index.html` memberi pautan ke modul ini tanpa mengubah bundle game sedia ada. GitHub Pages boleh menerbitkan folder ini bersama laman sedia ada.
